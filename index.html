Azure AD Setup Guide
Obiettivo

Registra un’app su Azure Active Directory per abilitare l’integrazione Outlook. Permission richieste: Mail.Send Tasks.ReadWrite User.Read

1
Accedi al portale Azure

Vai su portal.azure.com → Microsoft Entra ID

2
Registra una nuova applicazione

App registrations → New registration
Name: Maritime Fleet Dashboard
Redirect URI: https://micheledv74.github.io/maritime-dashboard/ (SPA)
Account type: Single tenant

3
Copia Client ID e Tenant ID

Incollali nella variabile AZURE_CONFIG nell’index.html.

4
Aggiungi API Permissions

Microsoft Graph → Delegated:
User.ReadMail.SendTasks.ReadWrite
→ Grant admin consent

5
Abilita token (SPA/PKCE)

Authentication → Access tokens ✓ · ID tokens ✓
Non creare Client Secret per app pubbliche su browser.

Prossimo Step

Quando hai Client ID e Tenant ID, comunica i valori e aggiungiamo MSAL.js per il login OAuth2 con Microsoft Graph.
